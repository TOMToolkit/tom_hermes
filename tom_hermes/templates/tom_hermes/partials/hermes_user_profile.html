{% comment %} HERMES card on the user-profile page. Rendered by the `hermes_profile_data` inclusion tag (tom_hermes/templatetags/hermes_extras.py), which is invoked by `tom_common.templatetags.user_extras.show_app_profiles` for every app that registers a `profile_details` integration point. Context (from hermes_profile_data): user — the logged-in User. hermes_profile — the User's HermesProfile instance. profile_data_list — list of {label, value, [is_password]} dicts, one row per displayable field. When `is_password` is set, the value is rendered as a masked password input the user can click to reveal — mirrors the tom_eso pattern (PR #44). When the credential is unset, value is the literal `[not set]` and is_password is absent, so the row renders as plain text. {% endcomment %}
